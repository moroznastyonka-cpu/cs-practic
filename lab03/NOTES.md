it diff показывает различия между версиями, только строки (+ и -).
git show показывает один коммит: кто, когда, что изменил.
git log список коммитов, с --stat добавляет статистику по файлам.

git log -S"def" ищет коммиты, где менялось количество "def". У меня ничего не нашёл, потому что функций в calc.py нет.

git blame показывает по каждой строке файла, каким коммитом она добавлена.
У меня: строки 1-4 коммит 703eaa3 (сложение), строка 5 789ec68 (вычитание), строки 6-8 a405e9f (умножение).



git restore lab03/calc.py вернул файл к состоянию последнего коммита (HEAD), затерев мои локальные правки (я удалила строки умножения, они вернулись).

git restore --source=HEAD~2 lab03/calc.py вернул версию файла из коммита двумя шагами назад (на момент вычитания, без умножения). Проверила через git diff: умножение пропало.

Разница: без --source берётся HEAD, с --source=<коммит> любой указанный коммит. Мои незакоммиченные правки в обоих случаях теряются безвозвратно — если бы они были нужны, пришлось бы сначала сделать git stash или коммит.
