рабочая папка-это папка на компьютере,где лежат файлы проекта,где я их редактирую
индекс-это промежуточная область. когда пишешь git add,файл попадает в индекс и готовиться к коммиту
коммит-это сохраненное состояние файла на определенный момент с пояснением
гит-это программа,которая следит за версиями файлов
гитхаб- это сайт в интернете,где храняться проекты.он использует гит

Использованные команды
git status-показывает состояние репозитория,какие файлы изменены,какие добавлены в индекс
git diff-показывает изменения между рабочей папкой и индексом (что изменено,но не добавлено)
git diff --staged-показывает изменения между индексом и последним коммитом (что попадёт в следующий коммит)
